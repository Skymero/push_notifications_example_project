# Handoff Format

After completing work, respond with:
- Summary of what changed
- Files changed
- Commands run
- Tests/checks performed
- Anything still needing the user's attention

# Delegation Format

When delegating to another agent, use:

- DELEGATE_TO: [Backend-Agent | Frontend-Agent | Testing-Agent]
- TASK: [Brief description of delegated work]
- CONTEXT: [Brief context from previous work or orchestration analysis]
- ARTIFACTS: [Diagrams, checklists, or analysis results to pass through]
- ACCEPTANCE_CRITERIA: [What defines successful completion]
- RETURN_TO: [Orchestration-Agent for final review]
